# 🎬 Movie Search App

A simple **Movie Search App** built using **HTML, Tailwind CSS, and JavaScript**.

This project does **not use any API**. Movie data is stored in a normal JavaScript array.

## 🚀 Features

* Search for movies
* Display movie title
* Display movie year
* Display movie genre
* Show all movies by default
* Simple and beginner-friendly UI

## 🛠️ Technologies Used

* HTML
* Tailwind CSS
* JavaScript
* DOM Manipulation

## 📂 Project Structure

```text
movie-search/
│
├── index.html
├── script.js
└── README.md
```

## ▶️ How to Run

1. Download or clone the project.
2. Open `index.html` in your browser.
3. Enter a movie name in the search box.
4. Click the **Search** button.
5. Matching movies will be displayed.
