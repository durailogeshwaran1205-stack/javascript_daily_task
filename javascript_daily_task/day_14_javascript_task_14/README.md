# 🧮 Basic Calculator

A simple and clean calculator built using **HTML, Tailwind CSS, and JavaScript**.

This project is beginner-friendly and supports basic arithmetic operations.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Modulus (%)
- Decimal numbers
- Clear button (C)
- Delete button (DEL)
- Simple responsive design

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript

▶️ How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start using the calculator.

No installation or setup is required.

🧑‍💻 How It Works

The calculator uses three JavaScript variables:

let firstNumber = "";
let operator = "";
let secondNumber = "";

For example:

10 + 5

The calculator stores:

firstNumber  = 10
operator     = +
secondNumber = 5

Then JavaScript calculates the result:

10 + 5 = 15
